# AI Notes

Copyable instruction blocks that point a coding agent to the [AtomForge](https://atom-forge.eu) package documentation and ask it for the facts of your project. The notes are a [BookMD](https://github.com/atom-forge/bookmd) book: the book is in [`book/`](book/), and it is published with the other AtomForge books.

| Note | Topic |
| --- | --- |
| [UI](book/ui.md) | Components, Tailwind spacing, reusable compositions |
| [Laminar](book/laminar.md) | Layers and dependency injection |
| [RPC](book/rpc.md) | Typed API conventions |
| [Attachment](book/attachment.md) | File attachments |
| [SvelteKit](book/sveltekit.md) | Placement of pages and components |
| [Env Reader](book/env-reader.md) | Typed configuration |
| [Date Format](book/date-format.md) | Date presentation |

Edit the Markdown files in `book/`; there is no other copy of the content.
